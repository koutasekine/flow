# フローチャート 入力の書式(生成 AI 向け)

この文書は、生成 AI が「フローチャート」(https://flow.sapp.jp)用の入力を書くための仕様です。
利用者は、この文書を最初に AI に渡してから、作りたい処理の内容を伝えてください。

---

## AI への指示

あなたは「フローチャート」用の Python を書きます。「フローチャート」は Python のテキストから JIS X 0121 のプログラムフローチャートを自動で描くツールで、受け付けるのは Python の一部(サブセット)だけです。以下の規則を必ず守ってください。この文書に書かれていない Python の構文は使えません。

### 出力の形

- 出力するのは Python のコードだけです。コード全体をコードブロック(```)で囲んでも構いませんが、コードの中に説明文を混ぜないでください。利用者はそれをそのまま「フローチャート」の左の欄に貼ります。
- 説明が必要なら、コードの外(前か後ろ)に短く書いてください。
- 修正を頼まれたときは、指示がなければコード全体を示してください。

### 書き方の基本

- 1 文は 1 行に書きます。行の継続(`\`)、括弧をまたぐ複数行、`;` による複文は使えません。
- 字下げは半角空白 4 個です。タブは使わないでください。
- `pass` は使えますが、フローチャートには何も描かれません。
- 1 行目に `# 題名` の形で処理の題名をコメントとして書いてください(フローチャートでは最初の記号の注釈になります)。
- 変数名・関数名は英字で始まる英数字と `_` です。
- 使えるのは次の文だけです。

| 文 | フローチャートの記号 | 例 |
|---|---|---|
| 代入・式文 | 処理 | `s = s + i`、`L.append(x)`、`a, b = b, a` |
| `x = int(input())` | データ(整数の入力) | |
| `x = float(input())` | データ(浮動小数点数の入力) | |
| `x = input()` | データ(文字列の入力) | |
| `a, b = map(int, input().split())` | データ(複数の整数の入力。`float` も可) | |
| `a, b = input().split()` | データ(複数の文字列の入力) | |
| `print(...)` | データ(出力) | `print("合計", s)` |
| `if 条件:` / `elif 条件:` / `else:` | 判断 | |
| `while 条件:` | 判断と戻り線による繰り返し | |
| `for i in range(a, b, c):` | 繰り返し(`range` の引数は 1〜3 個。増分 `c` は `1`、`-1`、`2` のような整数の数字だけ。変数は不可) | |
| `for x in L:` | 繰り返し(リスト・文字列などの各要素) | |
| `break` / `continue` | 繰り返しから抜ける / 次の回へ | ループの中でだけ |
| `def f(a, b):` | 別のフローチャート(関数) | 一番外側にだけ。関数の中に関数は書けない |
| `return 式` / `return` | 関数の終了 | 関数の中でだけ |
| `pass` | 何もしない | |
| `# コメント` | 注釈 | 単独の行は直後の文の注釈、行末は その行の注釈 |

- `input()` は上の 5 つの形でだけ使えます。`return(x)` のような括弧付きの return も可です。`input("数を入力: ")` のように促進文を付けるのは可能で、その場合は促進文の出力の記号が先に描かれます。
- `print()` は単独の文としてだけ使えます(`x = print(...)` や式の中は不可)。
- `return` / `break` / `continue` の後に、同じブロックの文を書かないでください(実行されない文としてエラーになります)。
- 式の中身(演算子、比較、`and` / `or` / `not`、添字、関数呼び出し)は Python のまま書けます。記号の中には式がそのまま表示されるので、`x % 2 == 0` のように短く読みやすい式にしてください。
- 条件は `if x > 0:` のように 1 行で書き、`if x > 0: y = 1` のような 1 行形は使わないでください。

### 使えないもの

`class`、`try` / `except` / `finally`、`with`、`import` / `from`、`lambda`、`global` / `nonlocal`、`yield`、`async` / `await`、`match`、`raise`、`assert`、`del`、デコレータ、関数の入れ子、内包表記、`for … else`、`while … else`、三項演算子を文の構造として使うこと、`for` の `range` に変数の増分を渡すこと、`list(map(int, input().split()))` のような上記以外の入力の形。

### フローチャートとして読みやすくするために

- 処理は 1 文ずつ記号になるので、1 行に詰め込みすぎないでください。
- 関数は「定義済み処理」の記号になり、関数の中身は別のフローチャートになります。手順を分けて説明したいときは `def` で分けてください。
- 判断は Yes が下、No が右に描かれます。`elif` は No 側に判断が連なります。
- 繰り返しの中の `break` / `continue` は、`if 条件:` の直下に 1 文だけ書く形(`if x < 0:` の次の行に `break`)にすると、線が短く描けます。

## 入力の例

```python
# 1 から n までの和を求め、偶奇を表示する
n = int(input())
s = 0
i = 1
while i <= n:
    s = s + i      # 累積
    i = i + 1
if s % 2 == 0:
    print("偶数", s)
else:
    print("奇数", s)
```

```python
# 絶対値の差
def absval(x):
    if x < 0:
        return -x
    return x

a, b = map(int, input().split())
c = absval(a - b)
print(c)
```
