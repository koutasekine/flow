# フローチャート — 記法仕様書(Python サブセット)

正本は納品 zip 内のこのファイル。アプリ内の「書き方」ボタンの説明はこの要約である。

## 1. 位置づけ

- 入力は Python の**サブセット**。本書に書かれた構文だけを受理し、それ以外は行番号付きのエラーにする(「フローチャートにできない」)。
- テキスト → 図は決定的(同じテキストから常に同じ図)。GUI の構造化編集 → テキストも可能(双方向)。正本は Python のテキストそのもので、JSON と SVG にはそのテキストを埋め込んで保存する。GUI 編集後の書き出しでは、関数定義とメインのフローチャートの文の元の順序、コメント、`range(...)` の書き方をそのまま保つ(文の字下げは 4 空白に正規化される)。
- 1 ファイル = メインのフローチャート 1 枚 + `def` ごとのフローチャート。トップレベルの文がメインのフローチャート(端子「開始」「終了」)、各 `def f(x)` は端子「f(x)」「f 終了」で囲む別の図。
- 図は JIS X 0121:1986 のプログラムフローチャート。反復は「判断+戻り線」で描く(ループ端記号は使わない)。

## 2. 字句

- 1 文は 1 行。行の継続(`\`)、括弧をまたぐ複数行、セミコロンによる複文は不可。
- 字下げは半角空白 4 個を推奨。ブロックごとに揃っていれば 2 個などでも受理し(タブは 4 空白として数える)、GUI 編集後の書き出しは 4 個に正規化される。同じブロックの中で深さが揃っていないとエラー。
- `#` から行末はコメント。**単独行のコメントは直後の文の注釈** 8.4(3) になり、行末コメントはその行の文の注釈になる(両方あれば「 / 」でつなぐ)。`else:` の直前の単独行コメントと `else:` の行末コメント、`pass` のコメント、末尾のコメントもテキストに保存される。
- 空行は無視。`pass` は記号を生成しない(テキストには残る)。

## 3. 文と記号の対応

| 構文 | 記号(JIS 条項) | 記号内の文字 |
|---|---|---|
| 代入・式文(`x = 1`、`s += i`、`a, b = b, a`、`L.append(x)` など) | 処理 8.2.1(1) | 原文のまま |
| `x = int(input())` | データ 8.1.1(1) | `整数 x を入力` |
| `x = float(input())` | データ | `浮動小数点数 x を入力` |
| `x = input()` | データ | `文字列 x を入力` |
| `a, b = map(int, input().split())`(`float` も可) | データ | `整数 a, b を入力` |
| `a, b = input().split()` | データ | `文字列 a, b を入力` |
| `input("促進文")` の促進文 | データ(出力)を入力の前に置く | `"促進文" を出力` |
| `print(a, b)` / `print()` | データ | `a, b を出力` / `改行を出力` |
| `if 条件:` | 判断 8.2.2(4)。Yes は下、No は右 | 条件(原文) |
| `elif 条件:` | 判断(No 側に入れ子) | 条件 |
| `else:` | 判断の No 側 | — |
| `while 条件:` | 判断 + 戻り線 | 条件 |
| `for i in range(b)` / `range(a, b)` / `range(a, b, c)` | 処理 `i = a` → 判断 `i < b` → 本体 → 処理 `i = i + c` → 戻り線。c は符号付き整数リテラルのみ。c < 0 なら `i > b`、`i = i - |c|` | |
| `for x in L:` | 添字を補って展開: 処理 `i = 0` → 判断 `i < len(L)` → 処理 `x = L[i]` → 本体 → 処理 `i = i + 1` → 戻り線。`i` はプログラム中で未使用の名前(`i`、`i2`、`i3`、…) | |
| `break` | 下記 5. | |
| `continue` | 下記 5. | |
| `def f(x, y):` | 別のフローチャート。開始の端子に `f(x, y)`、終了の端子に `f 終了` 8.4(2)。入れ子の def は不可 | |
| `f(...)` / `y = f(...)`(同じファイルで `def` した f を含む文) | 定義済み処理 8.2.2(1) | 原文のまま |
| 組込み関数の呼び出し(`len`、`abs`、`int` など) | 処理 | 原文のまま |
| `return 式` | 端子 | `式 を返す` |
| `return` / 関数末尾 | 端子 | `f 終了` |
| `# コメント` | 注釈 8.4(3) | コメント文 |

- 式はいっさい解釈せず原文のまま記号に書く(`==`、`!=`、`**`、`//` も Python のまま)。
- 判断の出口ラベルは `Yes` / `No` 固定。
- `return` は関数の中でだけ、`break` / `continue` はループの中でだけ書ける。`return` / `break` / `continue` の後に同じブロックの文があるとエラー(実行されない文)。

## 4. 受理しない構文(エラー)

- 文頭のキーワードが `class`、`try` / `except` / `finally`、`with`、`import` / `from`、`lambda`、`global` / `nonlocal`、`yield`、`async` / `await`、`raise`、`assert`、`del`、デコレータ(`@`)の文、`match` / `case` 文(変数名としての `match`・`case` は可)、`while` / `for` の `else`、`if x > 0: y = 1` のような 1 行に書く形、三重引用符の文字列
- 関数の入れ子(`def` の中の `def`)
- `for` の `range` の増分が整数リテラルでない場合、`range` の引数が 0 個または 4 個以上の場合
- `input()` を 3 章の 5 形以外で使う文(`list(map(int, input().split()))` など)
- `print()` を単独の文以外で使う文(`print(a) if x else print(b)` も不可)
- 式の中身は検査しないので、内包表記や lambda が式の一部として書かれていても処理記号にそのまま入る(推奨はしない)。

## 5. break / continue の描き方

break / continue は常に最も内側のループが対象。描き方は 2 通りで、どちらを使うかはツールが構造から決める。

**(a) 直線(特例)**: `if 条件:` の本体が `break`(または `continue`)1 文だけで `else` がなく、かつ

- break の場合: その `if` がループ本体に直接並んでいる(別の `if` の中にない)
- continue の場合: その `if` に至る経路がループ本体から `if` の Yes 側だけを通っている(No 側 = `else` の中にない)

のとき、**その判断だけ Yes を右(break)/左(continue)に出し、No を下に出す**。break の線はループの右レーン(No で抜ける線)に合流し、continue の線は while では戻り線の縦線に合流、for では増分の手前で背骨に合流する。

**(b) 結合子**: 上記以外は出結合子 `B1` / `C1`(数字はループ番号)で線を切り、ループの出口 / 条件の手前(for では増分の手前)に同名の入結合子を置く 8.4(1)。根拠は 9.2.2(1)「線が交差したり…するのを避ける必要がある場合」。

安全網: (a) で描いた図に線の交差が検出された場合、その図全体を (b) で描き直す。

## 6. 配置の約束(JIS との対応)

- 標準の流れは上→下、分岐は右 9.2.1(1)。
- 線は水平・垂直の直線のみ 9.1(1)。線は記号の上辺中央から入り下辺中央から出る。ひし形は頂点から出入りする 9.2.1(5)。
- 矢印は線の**終端 1 か所**にだけ付ける 9.2.1(2)。記号に入る線は、標準方向(下向き・右向き)でない区間を含むときだけ終端(記号の入口)に付ける。他の線に横から合流する線は合流点に付ける。背骨に縦に入る幹の線には付けない。角には付けない(角で終わる線は次の記号まで延ばす)。
- 線は交差させない 9.2.1(3)。合流は T 字で入れる 9.2.1(4)。
- 記号の寸法: 処理・データ・端子・定義済み処理は高さ 40、幅は基本 80(JIS の図の比 2:1)。文字が長い記号があれば、その図の中の同種記号すべての幅を、最も長い文字に合わせて 20 刻みで広げる(図の中で同種記号は同寸 9.1(2))。ひし形は幅:高さ = 1.8:1(JIS の図の比)を保ち、図の中で同寸。条件が長いときは空白の位置で最大 3 行に折り返し、最も小さくなる行数を選ぶ。結合子は直径 28。
- 行番号を記号識別子として記号の左上に表示できる 9.1(4)。
- **ページ分割**(設定「ページ分割」: なし / A4 縦 / A4 横。既定はなし): 図が 1 ページに収まらないとき、記号・ラベル・水平線にかからない高さで切り、切断線をまたぐ線ごとに出結合子・入結合子の対(同じ番号)を入れる 8.4(1)、9.2.2(1)。結合子の注釈(設定「結合子の注釈」: なし / 次の図へ・前の図から / n ページへ・n ページから。既定はなし。9.2.2(2) の「示してもよい」に基づく任意)。画面にだけページの枠と「k / N」を表示し、保存(SVG・PNG)と印刷には出さない。切った短冊は、ページの幅に余裕があれば同じページに左から右へ並べる(1 ページに収まる図は 1 ページにする)。1 本の線が切断線を何度またいでも、またぐごとに結合子の対を入れる。ループの出口(右のレーン)のように、切れ目の下で横に曲がって背骨に戻る線は、他の線・記号に触れない限り、下の結合子を背骨の上に移してまっすぐ下ろす。記号が隙間なく並んで切断位置が見つからない図は、そのページを A4 より縦に伸ばして描き、左下に警告を出す。同じページ内の結合子にはページ参照を付けない。関数の図は新しいページから始める。図の幅がページ幅を超えるときはそのページだけ縮小する。分割なしのときは従来どおり 1 枚の図。

## 7. 例

```python
# 1 から n までの和を求め、偶奇を表示する
n = int(input())
s = 0
i = 1
while i <= n:
    s = s + i      # 累積
    i = i + 1
if s % 2 == 0:
    print("偶数", s)
else:
    print("奇数", s)
```
