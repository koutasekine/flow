# フローチャート

Python(の一部)で書いた手順を、JIS X 0121:1986 のプログラムフローチャートとして描くブラウザアプリです。
`index.html` 1 ファイルだけで動き、インストールやアカウントは要りません。外部のサービスを読み込まず、書いた内容をどこにも送信しません。

学生が規格に沿ったフローチャートを描けるようになるためのツールで、規格から外れた図(曲線の線、ひし形の頂点以外から出る線、線の交差、矢印の付け忘れ)は作れないようになっています。

- Python を書くとフローチャートが自動で描かれる(1 文が 1 記号)
- 記号をクリックして、文字の変更・記号の挿入・削除ができる(線は手で引かない)。編集はテキストに反映される
- `def` で書いた関数は別のフローチャートになる
- 長い図は A4 のページに分け、ページをまたぐ線は結合子でつなぐ
- Python(`.py`)の上書き保存・別名で保存(Ctrl+S)。SVG・PNG・JSON で書き出し、印刷で PDF にできる
- 生成 AI に Python を書かせて、そのまま貼れる

## 使い方

公開版は https://flow.sapp.jp で使えます。
ダウンロードした `index.html` をブラウザで直接開いても使えます。

1. 公開版か `index.html` を、ブラウザ(Edge・Chrome など)で開きます。
2. 左の欄に Python を書きます。右にフローチャートが出ます。書き方は画面上部の「書き方」ボタンで見られます。
3. 右の記号をクリックすると、下に編集パネルが出ます。

初めて開いたときは空です。「例を読み込む」を押すと例が入ります。2 回目からは、前回の内容が入った状態で開きます。

## 生成 AI で Python を書かせる

入力が Python のテキストなので、生成 AI が書いた Python をそのまま貼るだけでフローチャートになります。
ただし、このアプリが受け付けるのは Python の一部だけです。

ChatGPT・Claude などの生成 AI に書いてもらうときは、最初に `docs/prompt_for_ai.md` の中身を AI に渡してください。
使える構文と書き方が書かれているので、AI がこのアプリ用の Python を書きます。

1. `docs/prompt_for_ai.md` の中身を AI に貼る(またはファイルを添付する)
2. 続けて、作りたい処理の内容を伝える(例:「2 つの整数を読んで最大公約数を求める手順」)
3. AI が書いた Python を、左の欄に貼る
4. 右のフローチャートと、左下のメッセージ(エラーがあれば行番号つきで出ます)を確認し、直したい点を AI に伝える

## 書き方

画面上部の「書き方」ボタンでも一覧を見られます。受け付ける構文の正式な仕様は `docs/記法仕様書.md` です。

| Python | フローチャートの記号 | 記号の中の文字 |
|---|---|---|
| `x = 式`、式文 | 処理 | 原文のまま |
| `x = int(input())` / `float(...)` / `x = input()` | データ(入力) | 整数 x を入力 / 浮動小数点数 x を入力 / 文字列 x を入力 |
| `a, b = map(int, input().split())` / `a, b = input().split()` | データ(入力) | 整数 a, b を入力 / 文字列 a, b を入力 |
| `print(a, b)` | データ(出力) | a, b を出力 |
| `if 条件:` / `elif` / `else:` | 判断(Yes は下、No は右) | 条件 |
| `while 条件:` | 判断と戻り線 | 条件 |
| `for i in range(a, b, c):` | `i = a` → 判断 `i < b` → 本体 → `i = i + c` → 戻り線 | |
| `for x in L:` | 添字 `i` を補って同じ形に展開 | |
| `break` / `continue` | 判断から右(左)へ抜ける線。深い入れ子では結合子 B1 / C1 | |
| `def f(x):` | 別のフローチャート。端子「f(x)」〜「f 終了」 | |
| `f(x)`(同じファイルで def した関数を含む文) | 定義済み処理 | 原文のまま |
| `return x` / `return` | 端子 | x を返す / f 終了 |
| `# コメント` | 注釈 | コメント文 |

- 1 文は 1 行。字下げは空白 4 個(Tab キーで空白 4 個が入ります)。
- `class`、`try`、`with`、`import`、`lambda`、内包表記、関数の入れ子などは使えません(行番号つきのエラーになります)。
- `return`・`break`・`continue` の後ろに文があるとエラーになります(実行されない文)。
- 字下げは 4 個を推奨しますが、ブロックごとに揃っていれば 2 個などでも読め、編集パネルで直した後は 4 個に揃えて書き出されます。
- 左のテキストに構文エラーがある間は、右の図が薄く表示され、記号をクリックしての編集はできません(直前の正しい図のままです)。

## 編集パネル

右の記号をクリックすると、下に編集パネルが出ます。

| 操作 | 内容 |
|---|---|
| 文字の欄を書き換えて Enter | 処理の文、条件、入力の変数と型、出力の値、返す値、注釈を変える |
| 「この記号の後に」「Yes 側の先頭に」「本体の先頭に」+「挿入する記号…」 | 記号(処理・入力・出力・if・if/else・while・for range・for in・return・break・continue)を挿入する |
| else を追加 / else を削除 | 判断に No 側のブロックを付ける / 外す |
| この記号を削除 | 記号を(中身ごと)削除する。ブロックが空になるときは `pass` が残る。elif を削除すると後ろの elif / else がつながる |
| 「開始」をクリック | 先頭に記号を挿入、または関数を追加する(何もない状態からも作れます) |

線を手で引くことはできません。構造(順次・分岐・反復)を操作すると、線はそれに合わせて引かれます。
編集の結果は左の Python に書き戻されるので、テキストと図は常に一致します。

## ページ分割

画面上部の「ページ分割」で なし / A4 縦 / A4 横 を選びます。既定は「なし」(1 枚の図)。

- 図を A4 の高さで切り、幅に余裕があれば同じページに左から右へ並べます(収まるなら 1 ページ)。
- 切れ目は同じ番号の結合子でつなぎます(JIS 9.2.2)。
- 「結合子の注釈」で、結合子に「次の図へ」や「n ページへ」の注釈を付けられます。既定は「なし」(報告書に貼るときにページ番号が食い違わないように)。
- 画面のページ枠と「k / N」は、保存・印刷には出ません。
- 記号が隙間なく並んでいて切れ目が取れない図は、そのページだけ A4 より縦に長くなり、左下に警告が出ます。
- 関数の図は新しいページから始まります。

## 保存と読み込み

正本は左の Python のテキスト(`.py`)です。

| ボタン | 動作 |
|---|---|
| 新規 | 空の状態で新しく始める |
| 開く | `.py`(`.txt`)、`.json`、このアプリで書き出した `.svg` を開く。ドラッグ & ドロップでも開ける |
| 上書き保存(Ctrl+S) | 開いている `.py` に上書きする(まだファイルがないときは保存先を選ぶ) |
| 別名で保存 | 保存先とファイル名を選んで `.py` を保存する |
| 書き出し… → SVG | ベクター画像。Python と設定を埋め込んであるので、このアプリで開いて編集を続けられる |
| 書き出し… → PNG | 画像(3 倍解像度) |
| 書き出し… → JSON | Python と設定(行番号の表示・ページ分割など)をまとめたもの |
| 書き出し… → 印刷 / PDF | ブラウザの印刷。ページ分割していれば 1 ページ 1 枚、送信先を「PDF に保存」にすると PDF になる |

- Chrome と Edge では、開いた・保存した `.py` にそのまま上書きします。ほかのブラウザでは、ダウンロードとして保存します。
- ボタンの右に開いているファイル名が出ます。後ろの `*` は保存していない変更があることを示します。保存していない変更があるときに「新規」「開く」「例を読み込む」を押すと確認が出ます。
- SVG・JSON を開いたときは、上書き保存の先にはなりません(次の上書き保存で保存先を尋ねます)。
- 書き出すファイルの名前は、開いている・保存したファイル名から付きます。

編集中の内容と設定(行番号の表示・ページ分割など)は、ブラウザの `localStorage` にも自動で保持されます。ページを閉じても、次に開くと続きから使えます。ただし、次の点に注意してください。

- 保持先はブラウザごと、サイト(URL)ごとです。別のブラウザや別の場所の `index.html` で開くと、別の保持先になります。
- ブラウザの「サイトデータの削除」で消えます。残したいフローチャートは、必ずファイルに保存してください。
- 上書き保存の先(開いていたファイル)は覚えていないので、開き直した後の最初の上書き保存では保存先を尋ねます。
- 同じ `index.html` を 2 つのタブで開いて編集すると、片方の内容がもう片方を上書きします。その場合は左下に警告が出ます。保持に失敗したとき(容量超過など)も警告が出ます。

他のツールで描いた SVG や PNG は開けません(図の形からではなく、埋め込まれた Python から描き直すためです)。

## 報告書に載せる

- TeX: ページ分割を A4 にして「印刷 / PDF」で PDF を作り、`\includegraphics[page=2,width=\linewidth]{flow.pdf}` のようにページを指定して読み込みます。余白を詰めるには `trim=10mm 10mm 10mm 10mm,clip` を付けます。
- Word・スライド: SVG か PNG を貼ります。シンプルスライド(https://slide.sapp.jp)には SVG をそのまま貼れます。

## 動作環境

Edge・Chrome などの最近のブラウザで動きます。ネット接続が必要なのは公開版のページを開くときだけで、ダウンロードした `index.html` は接続しなくても動きます。
